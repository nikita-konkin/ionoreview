# ИоноРазметка

Настольный инструмент для разметки и экспертной проверки ионограмм. Редактор
поддерживает полигоны в формате LabelMe, физические оси измерений и предложения
масок на основе кластеризации. Изображения и результаты обрабатываются локально.

- [Windows-сборка и GitHub Actions](docs/WINDOWS_BUILD.md)
- [Скачать актуальный Windows-релиз](https://github.com/nikita-konkin/ionoreview/releases/latest)
- [Дообучение визуальной модели и MCP](training/README.md)

## Возможности

- Рисование полигонов, редактирование вершин, перенос отдельных масок и групп.
- Множественное выделение и назначение общей метки прямо на ионограмме.
- Масштабирование, перемещение изображения, выбор области и окна дальности.
- Предразметка DBSCAN с автоматическим числом групп или K-means с заданным числом.
- Проверка предложений экспертом, история изменений и отмена действий.
- Режим независимой ручной проверки с отключёнными автоматическими подсказками.
- Открытие обычных изображений, рабочих наборов и каталога наборов.
- Импорт LabelMe и экспорт только принятых аннотаций.
- Подготовка LFS/HDF5 в изображения с числовыми матрицами и физическими осями.
- Отдельный экспериментальный контур QLoRA для визуальной модели.

Кластеризация выделяет похожие участки сигнала, но не устанавливает физическую
моду. Классы и корректность границ подтверждает эксперт.

Для слепой проверки набор может задавать `assistance_disabled: true` в манифесте.
В таком наборе недоступны автокластеры и импорт чужой разметки; ручное
редактирование и экспертная приёмка сохраняются.

## Быстрый запуск в Windows

Распакуйте полностью portable-архив Windows-сборки и запустите `IonoReview.exe`.
Папка `_internal` должна оставаться рядом с exe. Python для готовой сборки не нужен.

Приложение открывает `datasets/catalog.json` рядом с exe, если каталог существует.
Иначе оно предложит выбрать готовый набор, каталог наборов или папку изображений.
Для обычных изображений отдельно выбирается место рабочего набора и результатов.
Другой набор можно выбрать кнопкой **Открыть папку…**, через `Ctrl+O` или кнопкой
**Открыть другую папку…** в каталоге. У готового набора можно выбрать также
вложенную папку `images`, `arrays` или `annotations`: программа откроет весь набор.
Архив с одними JSON не содержит изображений; для просмотра нужен полный набор.
Подробности и самостоятельная сборка — в [инструкции Windows](docs/WINDOWS_BUILD.md).

Пользовательские ионограммы, аннотации и веса моделей в portable-архив не входят.
Подготовка исходных измерений и дообучение выполняются из Python-проекта.

## Запуск из исходников

Для редактора нужен Python 3.10+ с Tkinter. Команды ниже выполняются из корня
репозитория; пример окружения приведён для PowerShell в Windows.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-review.txt
```

Положите свои изображения в папку `input-images`, затем создайте рабочий набор:

```powershell
.\.venv\Scripts\python.exe -c "from ionoreview.folders import import_image_folder; import_image_folder('input-images', 'datasets/my-images')"
.\.venv\Scripts\python.exe -m ionoreview review datasets/my-images
```

Поддерживаются PNG, JPEG, BMP и TIFF. Редактор работает с копиями изображений,
применяет EXIF-ориентацию и использует первый кадр TIFF. Соседние корректные JSON
LabelMe могут быть импортированы как предварительная разметка. Существующая
рабочая папка при создании набора не перезаписывается.

Готовую библиотеку наборов можно открыть отдельно:

```powershell
.\.venv\Scripts\python.exe -m ionoreview library datasets
```

У обычных картинок нет числовых осей: координаты задаются в пикселях. Поля
физической дальности доступны только для наборов с соответствующими массивами.

## Работа в редакторе

1. Откройте набор через каталог или кнопку **Открыть папку…**.
2. Приблизьте интересующую область. Колесо изменяет масштаб ионограммы,
   `Shift` + колесо — окно по дальности; средняя кнопка перемещает изображение.
3. Нарисуйте полигоны вручную либо запустите **Авторазметку…**.
4. Исправьте границы и назначьте классы. Рамка выделения, `Ctrl`/`Shift` + щелчок
   и список объектов позволяют выбрать несколько масок. Меню меток применяется
   ко всему выделению.
5. Укажите эксперта и примите результат либо оставьте замечание для исправления.

`Ctrl+Z` отменяет действия, `Backspace` убирает последнюю точку незамкнутого
полигона, `Ctrl+S` сохраняет запись. Подробное описание кнопок, режимов мыши и
сочетаний клавиш находится в окне **Правила**.

В режиме выбора можно двигать вершины или маску целиком. Отметка переноса всей
группы включает совместное перемещение связанных полигонов. Разным частям одной
моды можно присвоить общий `group_id`; при этом их контуры остаются отдельными.

Доступные метки: `Signal`, `1E`, `1F`, `2F`, `3F`, `E`, `Es`, `Interference`.
`Signal` обозначает полезный сигнал без установленной моды. До начала работы
согласуйте протокол классов, в том числе использование `E` и `1E`.

Полигоны должны охватывать видимую полосу эха. Не заполняйте пустое пространство
между ветвями и не продолжайте след в невидимой области. Принятие пустого
результата требует явной отметки **Полезный сигнал отсутствует**.

## Предразметка кластерами

DBSCAN группирует плотные участки надпороговых точек и отделяет шум. В K-means
пользователь задаёт количество групп; изолированные точки предварительно
отбрасываются. Итоговое число кандидатов может уменьшиться после фильтрации.

Для числовых ионограмм параметры задаются в дБ, МГц и км. Для обычных изображений
используются яркостный признак и пиксели. Яркость изображения не является SNR.
Если на изображении есть подписи и поля графика, сначала приблизьте сам график
инструментом **Область**.

Кандидаты сначала показываются в предпросмотре. Их можно выбрать, добавить,
отклонить, исправить и разметить общим классом. Предпросмотр сам по себе не
меняет аннотацию и не попадает в экспорт.

Один кластер может состоять из нескольких отдельных контуров. Число кластеров
не равно числу физических мод. Соприкасающиеся следы могут объединяться, слабые
следы — теряться, а помехи — образовывать самостоятельные группы.

## Формат рабочего набора

```text
datasets/my-set/
  manifest.json       # изображения, размеры, источники, оси и контрольные суммы
  images/             # изображения для разметки
  arrays/             # необязательные NPZ с числовыми данными
  annotations/        # текущие JSON LabelMe с полями экспертной проверки
  history/            # предыдущие сохранённые версии
  settings.json       # настройки работы с набором
```

Каталог `datasets/catalog.json` объединяет несколько таких наборов. Все пути
изображений и массивов внутри набора относительные, поэтому набор можно
переносить вместе с его папками. **Сохранить набор как…** создаёт копию с
аннотациями и историей и переключает редактор на неё.

В NPZ используются ключи `db`, `freq_mhz`, `range_km`. Столбцы матрицы идут по
возрастанию частоты, строки сверху вниз — по убыванию дальности. Координаты
полигонов заданы в пикселях, начало — в левом верхнем углу. Для числовых наборов
пиксель изображения соответствует элементу матрицы; подписи и поля графика в
рабочий PNG не добавляются. NPZ открывается обычным `numpy.load`.

JSON совместим с полигонами LabelMe и содержит дополнительные поля `review`,
`provenance` и, при наличии, сведения о предложении модели или алгоритма.
Статусы проверки: `pending`, `accepted`, `changes`, `ambiguous`.
Изменение принятой записи возвращает её в ожидание проверки.

Текущая запись сохраняется атомарно; предыдущие версии остаются в истории.
Проверка ревизий предотвращает незаметную перезапись изменений другим окном.
Полные пути к изображению, исходнику и результату показаны в интерфейсе.

## Подготовка измерений LFS/HDF5

Дополнительные зависимости устанавливаются в окружение проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-prepare.txt
.\.venv\Scripts\python.exe -m ionoreview prepare --out datasets/my-soundings --project vendor/ionograms_handler input/recording.lfs
```

Подготовка использует загрузчик из `vendor/ionograms_handler`. Помимо LFS,
поддерживаются продукты `lfm_ionogram-*.h5` и `digisonde_ionogram-*.h5`.
Произвольные файлы HDF5 с параметрами или результатами детекции не считаются
ионограммами. Несколько исходников можно передать отдельными аргументами.

Для архива предусмотрены отдельные команды с продолжением обработки:

```powershell
.\.venv\Scripts\python.exe -m ionoreview.archive inventory input reports/inventory.json
.\.venv\Scripts\python.exe -m ionoreview.archive hydrate reports/inventory.json reports/hydration.json
.\.venv\Scripts\python.exe -m ionoreview.archive build reports/inventory.json datasets --loader vendor/ionograms_handler --hydration reports/hydration.json
.\.venv\Scripts\python.exe -m ionoreview.collect_png .
.\.venv\Scripts\python.exe -m ionoreview.verify_archive .
```

Исходники не перезаписываются. В рабочем наборе сохраняются PNG, числовой массив,
физические оси, метаданные и контрольные суммы. Нечитаемые файлы записываются в
отчёт. Для подготовки больших архивов настройте число процессов и резерв места
через параметры команды `build`; одновременно запускайте только один процесс
подготовки для одной библиотеки.

Дальность воспроизводит данные и соглашения загрузчика. Она может быть
относительной или заданной настройками приёма; такие особенности отражаются
в метаданных. Положение следа само по себе не подтверждает физическую моду.

## Экспорт и модели

Экспорт включает только записи со статусом `accepted`: PNG, JSON LabelMe, NPZ
при его наличии и манифест. Существующий экспорт не перезаписывается.

```powershell
.\.venv\Scripts\python.exe -m ionoreview export datasets/my-set exports/accepted-round
.\.venv\Scripts\python.exe -m ionoreview import datasets/my-set image_0001 proposal.json --author local-model
```

Импорт модели создаёт предварительную разметку и требует проверки экспертом.
Само наличие предложения не означает принятия. Перед обучением задайте
`train`, `validation` и `test` и не распределяйте фрагменты одного наблюдения
между разными частями. Для экспортированных групп учитывайте `group_id`.

Подготовка датасета, QLoRA, оценка качества и подключение MCP описаны в
[training/README.md](training/README.md). Эти функции отделены от Windows-редактора.

## Проверка кода

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest tests/test_review.py tests/test_clustering.py tests/test_archive.py tests/test_packaging.py -q
```

Тесты проверяют хранение аннотаций, экспертную приёмку, импорт и экспорт,
геометрию, кластеризацию и упаковку. Дополнительные проверки учебного контура
приведены в его инструкции.
