# ИоноРазметка

Небольшое настольное приложение для предварительной разметки и экспертной приёмки ионограмм. Работает локально, без сервера и отправки измерений в интернет.

## Проект и архив на диске N

Активный проект: **`N:\ionoreview`**. Запуск — **`Start-Review.cmd`**:
откроется каталог с поиском по дате, типу и станции. Выберите набор и нажмите
**Открыть набор**. Кнопка **Каталог…** в редакторе возвращает к выбору набора.
**`Start-Pilot.cmd`** сразу открывает прежние 12 ионограмм с разметкой и историей.

Наборы из `F:\MyData\ND\lfs` собраны в `datasets`: отдельные партии до 300
ионограмм для ЛЧМ HDF5, Digisonde HDF5 и LFS. `datasets/catalog.json` перечисляет
все готовые партии. В каждой есть `images`, `arrays`, `manifest.json` и
`annotations` для результатов. Новые записи имеют статус «Ожидает».
PNG не содержит полей графика; частота и дальность хранятся в NPZ. Палитровый PNG
сохраняет те же цвета turbo 15–60 дБ, что прежние картинки, и занимает меньше места.
Числовая матрица хранится как float32 без дальнейшего округления и прореживания.

Исходные записи общим объёмом свыше 140 ГБ остаются на F; на N находятся готовые
изображения и массивы для автономной разметки. Связь с исходником, SHA-256,
дата, передатчик и приёмник записаны в манифесте. Файлы параметров/детекции
`*.h5` не считаются ионограммами. Производные PNG не дублируют те же измерения.
Данные Digisonde здесь — наклонный приём сигналов другого вертикального зонда;
ось дальности может быть задана настройками приёма. Это отмечено в редакторе.

Итог и проверка: **`reports/PREPARATION.md`**, подробности и список исключённых
исходников — `reports/preparation_summary.json`. Некорректные/обрезанные записи
не включаются в каталог. Проверка читает все готовые PNG/NPZ, сверяет контрольные
суммы, размеры и физические оси. Существующие аннотации при подготовке сохраняются.

Повторная подготовка с продолжением: **`Prepare-Archive.cmd`**. Сначала он
инвентаризирует архив и читает облачные HDF5, затем создаёт недостающие изображения
и проверяет их. Нужен доступ к исходникам; исходные файлы не изменяются. На N
сохраняется резерв минимум 3 ГиБ, при его достижении подготовка останавливается.
Для проверки без подготовки: `python -m ionoreview.verify_archive N:\ionoreview`.
Не запускайте два процесса подготовки одновременно.

Копия научного загрузчика из `N:\ionograms-handler` находится в
`vendor/ionograms_handler/muf`; источник и версия описаны в `provenance`.
Подготовка использует эту зафиксированную копию. Соседний проект загрузчика
не меняется. Код хранится в локальном Git, сами наборы и отчёты исключены из Git.
В `references` собраны пять присланных файлов: научные документы и презентация.
Контрольные суммы — `provenance/references.json`.

Зависимости: `python -m pip install -r requirements-review.txt` для разметки,
`python -m pip install -r requirements-prepare.txt` для подготовки.
В Windows Python должен включать Tkinter. Проверка кода: `python -m pytest tests -q`.

## Открытие своей папки и выбор места результатов

Кнопка **Открыть папку…** открывает готовый рабочий набор с `manifest.json` либо обычную
папку с PNG, JPEG, BMP, TIFF. Во втором случае программа запросит место для нового рабочего
набора и создаст там отдельную папку с копиями PNG и аннотациями. Исходные картинки не
перезаписываются. В одной партии до 1000 изображений непосредственно выбранной папки.
Скрытого рекурсивного обхода диска нет. Ошибки чтения отдельных файлов записываются
в `manifest.json`. В TIFF используется первый кадр; EXIF-ориентация изображений применяется
при создании рабочего PNG.

Соседние JSON LabelMe с тем же именем импортируются как предварительная разметка,
если размеры, классы и полигоны корректны. Исходные JSON сохраняются; импортированные
объекты всё равно требуют экспертной приёмки. Ошибка аннотации не мешает открыть сам PNG.

**Сохранить набор как…** копирует весь рабочий набор, включая аннотации и историю,
в выбранное место и переключает редактор на новую копию. **Открыть папку** возле каждого
пути внизу окна открывает соответствующее расположение в Проводнике. Это отдельное
действие от выбора нового набора.

У обычных PNG/JPEG нет физических осей. В таком наборе редактор работает в пикселях,
а поля дальности в км отключены. Если картинка содержит подписи, белые поля и цветовую
шкалу, инструментом **Область** приблизьте только график перед автоматической разметкой.
Изображения нового набора имеют `split=unassigned`: перед обучением отдельно зафиксируйте
обучающую и независимую тестовую части.

## Перенос масок целиком

В режиме **Выбор / вершины** потяните левой кнопкой внутри существующей маски.
Все её вершины сдвигаются одинаково, без изменения формы. Белые вершины выбранного
полигона по-прежнему можно двигать отдельно. Отметка **При переносе двигать всю группу**
включает перенос всех полигонов с тем же `group_id`. Движение ограничено границами
исходного изображения. Один перенос отменяется через **Отмена / Ctrl+Z**. Щелчок без
перетаскивания не меняет принятие; фактический перенос возвращает запись в ожидание.

## Множественное выделение и общая метка

- Инструмент **Выделение** позволяет протянуть рамку вокруг нескольких полигонов.
  Выбираются контуры, пересекающие рамку. Ctrl/Shift добавляет рамку к выделению.
- В режиме **Выбор / вершины** Ctrl/Shift + щелчок добавляет или исключает отдельную
  маску. В списке **Объекты** также доступны Ctrl и Shift; Ctrl+A на графике выбирает всё.
- После выделения меню меток появляется прямо на графике. Нажмите **1F**, **2F**, **E**
  или другую метку: она назначится всем подсвеченным полигонам одним действием.
  **Вся группа** выбирает все части соответствующего кластера/группы.
  **Снять выделение** убирает меню. Правый щелчок повторно открывает его.
- Можно выделять кандидатов непосредственно в предпросмотре. Нажатие метки добавит
  в разметку только выбранные части и оставит прочие кандидаты в предпросмотре.
  **Удалить / Delete** отклоняет выбранные кандидаты или удаляет выбранные маски.
- Меню и выделение не меняют данные до выбора класса. Назначение метки и добавление
  выбранных кандидатов отменяются одним **Ctrl+Z**. Геометрия масок при этом не меняется.
- Если другой класс назначается только части группы, выбранные части отделяются
  в новую группу: остальные полигоны сохраняют прежние метки. Для смены класса всей
  группы сначала нажмите **Вся группа**. Несколько выбранных масок можно перемещать вместе.

## Полуавтоматическая разметка кластерами

1. Приблизьте интересующую область и нажмите **Авторазметка…**.
2. **Авто (DBSCAN)** определяет количество групп по плотности сильных точек и выделяет
   шум. **Вручную (K-means)** использует указанное число от 1 до 30. После отсева слишком
   маленьких или узких групп итоговое число кандидатов может быть меньше заданного.
3. Укажите порог и масштабы связи по двум осям. Для числовых ионограмм это дБ, МГц и км.
   Для обычных картинок — яркость 0–255 и пиксели. Масштабы связи также задают относительный
   вес координат в K-means. Параметр числа соседей относится только к DBSCAN.
4. Нажмите **Найти кластеры**. Расчёт идёт в фоне. Оранжевые K1, K2 и т.д. — только
   предпросмотр: они ещё не сохраняются как маски и не попадают в экспорт.
5. **Добавить кластеры** добавляет кандидатов как `Signal`, сохраняя прежние маски.
   **Скрыть кандидаты** убирает только предпросмотр. Добавление можно отменить.
6. Удалите помехи, исправьте границы и назначьте класс через **Сменить класс**. Для
   нескольких частей используйте выделение рамкой или **Вся группа** в меню меток. Доступны
   `Signal`, `1E`, `1F`, `2F`, `3F`, `E`, `Es`, `Interference`. Согласуйте использование
   `E` и `1E`, чтобы не смешивать две метки одного физического класса.
7. Примите исправленный результат от имени эксперта.

Алгоритмы здесь не обучены распознавать физические моды: соприкасающиеся следы могут
объединиться, разорванные — разделиться, слабые — не пройти порог. Для обычных цветных
картинок применяется яркостный признак с исключением серых/белых полей; это не оценка SNR.
Вычисления по числовой матрице не зависят от ползунков её отображения. Минимальная полоса
отсекает узкие вертикальные помехи, но может удалить полезные короткие следы.

В ручном K-means до разделения отбрасываются изолированные точки по критерию плотности.
При построении контуров закрываются короткие пробелы и мелкие отверстия, удаляются
малые компоненты; большие пустые области между ветвями сохраняются. Разным кластерам
соответствуют разные цвета и одна подпись K1/K2 на группу. Количество кластеров и число
их отдельных контуров показываются отдельно: четыре кластера могут иметь больше четырёх
контуров при разрывах следа. Число кластеров не равно числу физических мод.

Границы кандидатов расширяются на один исходный пиксель, чтобы тонкие следы можно было
редактировать полигонами. Отверстия между ветвями не заполняются: такие контуры разбиваются
на части одной группы. Обработка ограничена 20000 надпороговыми точками и 100 кластерами
за один запуск; при превышении повысьте порог или сузьте область. Параметры добавленной
авторазметки сохраняются в `auto_proposals`, автор метода — в флагах полигонов.

Основы методов: [DBSCAN](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.DBSCAN.html),
[K-means](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html).

## Запуск

Дважды нажмите **Start-Review.cmd** в этой папке: откроется каталог наборов.
**Start-Pilot.cmd** открывает прежний пилот `datasets/pilot` напрямую.

Из PowerShell:

```powershell
Set-Location N:\ionoreview
python -m ionoreview library datasets
```

В текущем окружении необходимые зависимости уже установлены. Для переноса нужен Python 3.10 или новее с Tkinter и пакеты из `requirements-review.txt`. Для подготовки новых наборов дополнительно нужны зависимости проекта `ionograms-handler`.

При запуске открывается последний сохранённый случай, а при первом запуске — первая
ожидающая ионограмма. Новые рабочие папки можно открывать из самого приложения.

## Первый набор

Подготовлены **12 ионограмм NIC1/NIC2** за 17, 18 и 24 октября 2026 года. Источники — HDF5 из `F:\MyData\ND\lfs\ionozond_data`, соответствующие уже отобранным PNG из `ionozond_data_selected`. Это небольшой целевой пилот, не случайная репрезентативная выборка.

Загрузка выполнялась через `muf.loader` из `N:\ionograms-handler`. Проект и исходные измерения не изменяются. Читается ионограмма из SNR; повторной обработки комплексного окна эха и фильтрации нет. Сохранены полная доступная дальность, матрица в дБ, физические оси и контрольные суммы. Поэтому изображения отличаются от отфильтрованных иллюстраций в исходной подборке.

В `F:\MyData\ND\lfs\ionozond_data_selected\FORMATS.md` отмечена нестабильность абсолютной дальности части наблюдений 18 и 24 октября. Положение следа по дальности само по себе не подтверждает класс моды. Подпись оси здесь воспроизводит данные загрузчика, а не исправляет эту проблему измерений.

Первоначальные пять черновиков ассистента сохранены в `proposals`. Текущая разметка
в `annotations` содержит исправления эксперта: на момент переноса приняты все
12 случаев. Используйте текущие аннотации; первоначальные черновики сохраняются
для истории и не заменяют их.

Дни разделены целиком: 17 октября — `train`, 18 октября — `validation`, 24 октября — `test`. Тестовые случаи не следует показывать локальной модели как примеры или использовать для настройки запроса. Для окончательной проверки алгоритма эксперт должен размечать тестовые данные независимо от его предсказаний.

## Как проводить приёмку

1. Укажите своё имя в поле **Эксперт**.
2. Выберите изображение. В списке диапазонов есть окна **1000–5000**, **1500–2000**, **2000–2500**, **2500–3000**, **2700–3100**, **3000–3500**, **3500–4000**, **4500–5000 км**. Для произвольного узкого окна введите нижнюю и верхнюю границы в поля **Дальность, км** и нажмите **Показать** или Enter. Например, можно задать 2700–2800 км. Меняется только вертикальный обзор; текущий диапазон частот сохраняется.
3. Переключайте **Маски**, чтобы сопоставлять контуры с исходником. Нижние ползунки меняют только отображение шкалы дБ и прозрачность; исходная матрица и координаты разметки не меняются.
4. Для нового объекта выберите класс и инструмент **Полигон**. Ставьте вершины щелчками, затем нажмите **Enter**, правую кнопку или **Замкнуть**. Неверную последнюю точку убирают кнопкой **Убрать точку**, клавишей **Backspace** при фокусе на графике или **Ctrl+Z**. Можно последовательно убрать несколько точек. Кнопка отключена, когда незавершённых точек нет, и не удаляет готовые маски. **Esc** отменяет весь незавершённый полигон.
5. Для исправления выберите объект в списке или щёлкните внутри него в режиме **Выбор / вершины**. Перетаскивайте белые вершины. Можно сменить класс, удалить полигон, отменить последнее изменение через **Ctrl+Z**.
6. **Группа…** объединяет несколько полигонов одной моды: одинаковый номер означает один экземпляр, 0 убирает группировку. Не объединяйте разные моды только потому, что они обе имеют класс `Signal`.
7. Примите результат, отправьте на исправление или отметьте как неоднозначный. Для двух последних решений нужен комментарий. Кнопки решения сохраняют результат и открывают следующий случай. **Ctrl+Enter** — принять и перейти далее.

Для точного приближения есть несколько способов:

- **Колесо над ионограммой** приближает или отдаляет график относительно курсора. Элементы управления и левая панель остаются на месте. **Shift + колесо** меняет масштаб только по дальности, сохраняя весь текущий диапазон частот.
- **Область**: выберите инструмент и протяните прямоугольник левой кнопкой вокруг нужного участка. После отпускания этот участок займёт график; программа вернётся в режим выбора вершин.
- **Вокруг масок** приближает выбранный полигон с небольшими полями. Если объект не выбран, приближаются все маски сигнала текущего изображения. Для ещё не размеченного изображения используйте прямоугольник или границы в километрах.
- Кнопки **+ / −** меняют масштаб относительно центра. Средняя кнопка мыши сдвигает вид, **Весь кадр** возвращает полный обзор.

Масштабирование, перемещение и выбор диапазона не изменяют координаты полигонов, статус приёмки или файлы аннотаций. Исходные пиксели при большом увеличении показываются без сглаживания. Минимальная ширина окна ограничена двумя исходными интервалами сетки; увеличение не добавляет измерительного разрешения.

Полигоны описывают видимую полосу полезного эха. Не следует заполнять всё пространство между ветвями либо дорисовывать невидимое продолжение. Для слабых и разорванных участков правила следует согласовать на первой партии. `Signal` означает полезное эхо без установленного класса моды. Доступны также `1E`, `1F`, `2F`, `Interference`.

Принятие пустой разметки требует явной отметки **Полезный сигнал отсутствует**. Эта отметка несовместима с полигонами сигнала. Любая правка принятого случая возвращает его в ожидание и требует повторной приёмки. Поле имени — запись об эксперте, не система аутентификации и не электронная подпись.

При переходе между случаями правки сохраняются автоматически. **Ctrl+S** сохраняет немедленно. Незамкнутый полигон надо закончить или отменить перед переходом. Имя эксперта сохраняется при сохранении записи.

## Где сохраняются результаты

Внизу главного окна постоянно видны четыре полных пути: исходное **Измерение** HDF5/LFS,
**PNG для разметки**, текущий **Результат JSON**, **Последний экспорт**. Для каждого есть
кнопка **Копировать**. Поля доступны для выделения, но не меняют расположение файлов.
Путь JSON отображается и для ещё не сохранённого случая; файл появится при сохранении.
Папка последнего экспорта сохраняется в настройках набора и восстанавливается при запуске.

Кнопка **Правила** открывает отдельную прокручиваемую справку с описанием всех кнопок,
полей, инструментов, действий мыши и горячих клавиш, а также правилами разметки текущего
набора. Окно справки можно оставить рядом с главным окном.

Внутри `datasets/pilot`:

- `manifest.json` — исходные пути и SHA-256, время, станции, части выборки, параметры отображения.
- `images/` — PNG без подписей и полей графика; один пиксель соответствует одному элементу матрицы.
- `arrays/` — NPZ с `db`, `freq_mhz`, `range_km`. Столбцы идут по возрастанию частоты, строки сверху вниз по убыванию дальности. Координаты полигонов — пиксельные центры, начало в левом верхнем углу.
- `annotations/` — текущая разметка в совместимом с LabelMe JSON с дополнительными полями `review`, `provenance`, `proposal`.
- `proposals/` — исходные пять черновиков ассистента до исправления экспертом.
- `history/` — предыдущие сохранённые версии. Статусы: `pending`, `accepted`, `changes`, `ambiguous`.

Сохранение JSON выполняется через временный файл и атомарную замену. Версия записи защищает от незаметной перезаписи правок другим окном. Не закрывайте программу принудительно в момент записи. Если после аварии остался `annotations/*.lock`, закройте все окна редактора и удалите только соответствующий файл блокировки.

## Экспорт для модели

Кнопка **Экспорт принятых…** создаёт новую папку `accepted_<дата-время>`. Экспортируются **только принятые экспертом случаи**: PNG, JSON LabelMe, NPZ с осями и манифест. Существующие экспорты не перезаписываются. Папки `train`, `validation`, `test` сохраняют разделение по дням.

Экспорт — набор данных, а не автоматически обученная модель. Для LoRA или Mask R-CNN понадобится преобразование в конкретный формат её обучения. Полигоны с одинаковым непустым `group_id` надо объединять в один экземпляр. `Signal` и конкретные классы мод нельзя бездумно смешивать при постановке задачи классификации: правила использования общего класса определяют перед обучением.

## Подключение локальной модели

Готова граница обмена файлами. Модель должна возвращать LabelMe JSON **для переданного PNG**, в его исходных пиксельных координатах. Пример структуры:

```json
{
  "version": "5.5.0",
  "imagePath": "case_001.png",
  "imageWidth": 573,
  "imageHeight": 1093,
  "shapes": [
    {
      "label": "Signal",
      "points": [[100, 700], [120, 700], [120, 705], [100, 705]],
      "shape_type": "polygon",
      "group_id": 1,
      "flags": {}
    }
  ]
}
```

Это пример формата, не физическая разметка. Координаты рамок или нормализованные координаты 0–1000 предварительно преобразуют; приложение не угадывает их смысл и не исправляет выходящие за изображение вершины.

Импорт через кнопку **Импорт разметки LabelMe…** заменяет текущие полигоны, сохраняя прежнюю версию в истории. Укажите автора или название модели. Импорт всегда получает статус ожидания, даже если в исходном JSON заявлено принятие.

Для автоматизации через MCP или обычный скрипт:

```powershell
python -m ionoreview import datasets/pilot case_001 candidate.json --author local-vlm
python -m ionoreview export datasets/pilot exports/accepted_round_1
```

Не импортируйте разметку в открытый редактируемый случай одновременно с работой эксперта: при конфликте версий программа потребует переоткрыть набор. Реальный вызов локальной модели и дообучение ещё не подключены: для этого нужны её название и API.

## Подготовка новых исходников

```powershell
python -m ionoreview prepare --project vendor\ionograms_handler --out datasets/next_batch F:\path\recording.h5
```

Поддерживаются форматы научного загрузчика, в том числе LFS и HDF5. Несколько файлов задаются отдельными аргументами. Для всего архива используйте Prepare-Archive.cmd. Команда подготовки отдельного набора отказывается перезаписывать существующую папку.

`python prepare_pilot.py` повторяет подбор текущего пилота из исходной папки отобранных PNG, если `datasets/pilot` ещё не существует. Это создаёт чистый набор без пяти черновиков.

## Проверка кода

```powershell
python -m pytest tests/test_review.py -q
```

Проверяются явная приёмка, отрицательные примеры, история и конфликт версий, импорт, экспорт только принятых, контроль изображений и осей, сохранение геометрии и настольный интерфейс. Тесты используют временные данные и не принимают реальные ионограммы от имени пользователя.
